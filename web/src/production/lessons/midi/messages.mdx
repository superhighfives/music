---
title: "Inside a MIDI message"
---

<p>A MIDI message is a few bytes. Each byte is eight bits, and the first bit tells the instrument what kind of byte it is: 1 for a status byte, which says what's happening, and 0 for a data byte, which says how much. Only seven bits are left for a value, so MIDI 1.0 values run from 0 to 127.</p>

<Steps>
  <li><div><b>Read the status byte in two halves.</b> The first four bits say what kind of message it is (1001 is Note On, 1000 Note Off, 1011 Control Change). The last four say which channel, 0000 to 1111, which Live shows as channels 1 to 16.</div></li>
  <li><div><b>A Note On with velocity 0 means Note Off.</b> Many keyboards send that instead of a real Note Off, so don't be surprised to see it.</div></li>
  <li><div><b>Watch it happen.</b> Install MIDI Monitor (free, by Snoize), play a key on Move and move a knob. Each line is one message: status, then data.</div></li>
  <li><div><b>Mind the octave names.</b> Note 60 is middle C. Live calls it C3; the Theory book, and most of the world, calls it C4. Same note, two naming schemes.</div></li>
</Steps>
<Note label="Why 127:">Values are seven bits because the eighth marks the byte as data. Pitch bend needs finer steps, so it joins two data bytes into 14 bits. On the original five-pin cable MIDI ran at 31,250 bits a second, so a three-byte message took about a millisecond; over USB it's far faster.</Note>
